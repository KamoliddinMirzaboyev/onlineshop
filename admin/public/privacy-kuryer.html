BB Kuryer — Maxfiylik siyosati

Oxirgi yangilanish: 2026-07-31 · Ilova: uz.barakalibozor.kuryer

Ushbu siyosat BB Kuryer (Barakali Bozor kuryer ilovasi) qanday ma’lumotlarni qayta ishlashini tushuntiradi.

1. Qaysi ma’lumotlar yig‘iladi

  • Hisob: login, ism, telefon (admin tomonidan berilgan / kuryer yangilagan).
  • Buyurtmalar: yetkazib berish manzili, mijoz telefoni, buyurtma holati — ish vazifasini bajarish uchun.
  • Joylashuv (GPS): ilova ochiq bo‘lganda kuryer joylashuvi (marshrut va yetkazish nazorati uchun).
  • Qurilma: push-bildirishnoma tokeni (FCM), ilova versiyasi.

2. Maqsad

Ma’lumotlar faqat yetkazib berish xizmatini ko‘rsatish, buyurtmalarni boshqarish, bildirishnomalar yuborish va xizmat sifatini yaxshilash uchun ishlatiladi. Reklama uchun uchinchi tomonlarga sotilmaydi.

3. Uchinchi tomon xizmatlar

  • Firebase Cloud Messaging (push)
  • Google Maps / Yandex (foydalanuvchi ixtiyori bilan navigatsiya)
  • Barakali Bozor backend API (allfoodapi.webportfolio.uz)

4. Saqlash va xavfsizlik

Ma’lumotlar himoyalangan serverlarda saqlanadi. Kirish faqat autentifikatsiyalangan kuryer va vakolatli adminlarga beriladi. Aloqa HTTPS orqali amalga oshiriladi.

5. Huquqlaringiz

Profil ma’lumotlarini ilovada yangilashingiz mumkin. Hisobni o‘chirish yoki ma’lumotlar bo‘yicha so‘rov uchun Barakali Bozor administratsiyasiga murojaat qiling.

6. Bolalar

Ilova 13 yoshdan kichik bolalar uchun mo‘ljallanmagan.

7. Aloqa

Savollar: Barakali Bozor / All Foods qo‘llab-quvvatlash xizmati orqali.
